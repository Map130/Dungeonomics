# D&D Eco — Живая экономика для настольных RPG

Open-source инструмент для мастера настольных RPG (прежде всего D&D). Мастер один раз описывает регион — узлы (города, деревни, лагеря), дороги между ними и товары. Дальше действия игроков и события мира сами меняют цены, наличие товаров и торговые потоки. Ручная бухгалтерия не нужна.

Идея заимствована из экономики [Mount & Blade: Bannerlord](https://www.taleworlds.com/en/Games/Bannerlord).

## Статус

**Стадия дизайна.** Идёт разработка Python-прототипа ядра симуляции.

Документация:
- [`REQUIREMENTS.md`](REQUIREMENTS.md) — продуктовые требования v1
- [`MODEL.md`](MODEL.md) — математическая модель v1

## Как это работает

- Шаг симуляции — один игровой день.
- Цены — это множитель к базовому прайс-листу (PHB или хоумбрю), зажатый в настраиваемый коридор.
- Узлы связаны только через торговые потоки: если разница цен превышает стоимость пути, часть запаса «едет» с задержкой.
- Каждое изменение цены объясняется: «хлеб в Редвотере подорожал, потому что дорога из Мельничного заблокирована (×2.5, осталось 7 дней) и запас упал до 38%».
- Мир воспроизводим: один seed → одинаковый прогон, откат и повтор дня дают тот же результат.

## Архитектура (план)

```
Python-прототип → порт ядра в Rust → компиляция в WASM → офлайн-PWA
```

- **Ядро (ddeco/):** Python-библиотека — симуляция, эффекты, лог причин.
- **Notebook (notebooks/):** калибровка параметров, визуализация, сверка с аналитикой.
- **Мир:** два TOML-файла — `world.toml` (описание, версионируется) и `state.toml` (состояние, автосохранение).
