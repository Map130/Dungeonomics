# Decision log

Format: `## D<n> · YYYY-MM-DD · title` — what was decided, why, which `§` it affects.
Decisions D1–D3 were made in M1 and recorded after the fact (the date is the commit that implements them).

## D1 · 2026-11-04 · World and save format — TOML
The world description `world.toml` (edited and shared) and the autosaved `state.toml` are kept
separate. Autosave is periodic by wall-clock time, not on every tick. Undo and replay work on
in-memory snapshots, so losing float bits in TOML does not affect determinism.
Why: human-readable, fits both community worlds and a save format.
Affects: REQUIREMENTS §10.1, §5.9; MODEL §8.4. Commit `cf61058`, plan `m1-python-prototype.md`.

## D2 · 2026-11-04 · Base price list P0_g — from `references/gear.csv`
The CSV is generated by `scripts/extract_gear.py` from a saved D&D equipment catalogue.
Coins are normalised to gold (pp=10, gp=1, ep=0.5, sp=0.1, cp=0.01). `worlds/example_region.toml`
is tied to these prices.
Why: a ready, complete PHB-level price list; no manual entry needed.
Affects: REQUIREMENTS §10.4; MODEL §2 (P0_g), §10.6 (partly). Commit `85457e8`. **Superseded by D5** (SRD 5.1).

## D3 · 2026-11-04 · Production chains deferred to v1.1
In v1 goods are independent. The code keeps an extension point: demand for chain inputs is added
to D_ig without reworking the tick.
Why: first get the single-level model stable; chains complicate it.
Affects: REQUIREMENTS §10.2; MODEL §5.13, §10.2. Plan `m1-python-prototype.md`.

## D4 · 2026-11-18 · Name — Dungeonomics, licence — MIT
The public name of the project and repository is Dungeonomics (`dungeonomics`), without an ampersand.
Internal package names (`ddeco`, `ddeco-core`, `ddeco-wasm`, `ddeco-web`) do not change.
Licence MIT (previously `MIT OR Apache-2.0` in Cargo, TBD in the README).
Why: the project goes public on GitHub; MIT is the simplest for a GM tool.
Affects: REQUIREMENTS §10.7.

## D5 · 2026-11-18 · Project goes English; UI and reasons log get EN + RU i18n
Since the project is public OSS: specs, docs, code comments and new commit messages are in
English (old history stays as is). The core stops emitting Russian text: the reasons log becomes
structured (message key + params), and the web UI renders it via an EN/RU catalog, EN by default.
The base price list moves from the dm-stuff.ru catalog to the SRD 5.1 equipment list (CC-BY-4.0),
superseding D2. Commits and PRs carry no Claude attribution.
Why: an English-speaking audience on GitHub, a clean licence for the data, RU users keep their UI.
Affects: REQUIREMENTS §5.8 (reasons log), §10.4; MODEL §2 (P0_g), §5.12. Plan `m4-open-source.md`.

## D6 · 2026-11-18 · Event presets instead of production chains in M5
Production chains stay in v1.1 (D3). One-click event presets in the UI (craftsman killed, blight,
army billeted, epidemic, bandits, bridge collapsed) cover the table use case and expand into
ordinary effects. Road effects now reach trade and caravans (spec §2/§5.6 compliance, R15).
Affects: REQUIREMENTS §5.8; MODEL §5.6. Plan `m5-event-presets.md`.
